Ticket fiscal · ARCA (ex AFIP)

3 Opciones de Integración

01
Vía Tango Restó
El kiosko envía el pedido por API → Tango genera el ticket fiscal nativo. Sin desarrollo adicional. Tango ya está homologado por ARCA. Necesita impresora Hasar o Epson conectada.
Complejidad:
BAJA
02
Controlador Fiscal Nueva Tecnología
Equipo físico homologado por ARCA. Modelos: Hasar, Epson, Sam4s. Requiere técnico certificado (30 días). Se comunica con ARCA en forma periódica. Costo: ~USD $850–1.000.
Complejidad:
MEDIA
03
API ARCA Directa
Web Services SOAP de ARCA. Requiere certificados digitales + CUIT configurado + punto de venta dado de alta. Simplificadores: TusFacturasAPP, AfipSDK, FacturaP.ar.
Complejidad:
ALTA

App Web + QR

¿Cómo funciona?

1
📱 Escaneo QR en el local
Cada mesa / mostrador tiene un QR impreso. Al escanearlo, abre la web de Mr. Tasty con el local ya configurado automáticamente.
2
🍔 Elige y arma su pedido
PWA (Progressive Web App) — funciona en cualquier celular sin instalar nada. Menú actualizado en tiempo real.
3
💳 Pago con MP o MODO
Checkout via Mercado Pago o MODO. El pago genera automáticamente la comanda en Tango Restó via API.
4
⏳ Espera con número de orden
El cliente recibe un número de pedido. El staff ve los pedidos en un panel simple y los marca como "listos".
5
📲 WhatsApp: "Tu pedido está listo"
Cuando el staff aprieta "Listo", el sistema envía automáticamente un WhatsApp al cliente: "🍔 Tu pedido #247 está listo para retirar. ¡Buen provecho!"

App Web + QR

Arquitectura Low Cost

📱 Frontend — PWA React
Progressive Web App. Se abre desde el QR, sin instalación. Menú dinámico, carrito, checkout. Funciona offline para ver el menú.
⚙️ Backend — Node.js + API REST
Gestión de pedidos, locales, menú. Se conecta con Tango Restó API, MP Checkout Pro, MODO y WhatsApp Business.
🍽️ Integración Tango Restó
Misma API que el kiosko físico: RestoAperturaComandasMostradorDelivery. Auto-envío a cocina + ticket fiscal ARCA.
📲 WhatsApp Business API (Twilio/Meta)
El staff marca el pedido como "listo" en el panel admin → dispara mensaje automático al número del cliente.
🖥️ Panel Admin — Staff
Interfaz simple web para staff. Muestra pedidos en cola, botón "Listo" por pedido. Sin hardware adicional — funciona en tablet o celular del local.
Flujo de datos
📱 Cliente escanea QR → PWA
💳 MP Checkout Pro / MODO link de pago
⚙️ Backend → POST Tango Nexo API
🍳 Tango → Comanda cocina + Ticket ARCA
🖥️ Staff panel → "Pedido listo" → trigger WA
📲 WhatsApp: "Tu pedido #247 está listo 🍔"
Hosting: AWS / DigitalOcean ~USD $400/mes
